# Paper draft

First draft of the paper on FOPSO-GWO tuning of the arm's FOPID controllers, in Springer's
proceedings class (`svproc`), not tied to any particular conference.

| File | Contents |
|---|---|
| [`main.tex`](main.tex), [`main.pdf`](main.pdf) | the manuscript and its compiled PDF |
| [`references.bib`](references.bib) | the bibliography (`spmpsci` style) |
| `svproc.cls`, `spmpsci.bst` | Springer's class and BibTeX style, from the author package |
| [`figures/`](figures) | the three figures (PDF) and [`make_figures.py`](figures/make_figures.py), which draws them |
| [`paper_numbers.m`](paper_numbers.m) | the few numbers that no stored result file holds |

## Building

```bash
cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

The draft needs the LaTeX packages amsmath, graphicx, booktabs, multirow, algorithm and
algpseudocode; Overleaf has all of them.

## Where the numbers come from

Everything is regenerated by the repository's code; nothing in the paper is typed in by hand
without a source.

| Paper | Source |
|---|---|
| Table 1 (arm) | `robot_params.m` |
| Table 2 (baselines against the published values) | `results/table_gains/summary.md` Sect. 1, after `main('table')` |
| Table 3 (constants of $J_W$) | any stored `whole` run, `fitness.whole` and `reference`; e.g. `results/optimizer_runs/fopso_gwo_whole_seed6.mat` |
| Table 4 (settings) | `hybrid_fopso_gwo.m` defaults, `tune_fopid_hybrid.m` |
| Table 5, Fig. 1(a) (eight runs) | `results/optimizer_runs/fopso_gwo_{whole,fbpa,paper}_seed1..8.mat` (`fbpa` is the file name of $J_T$, `paper` of $J_{ITAE}$); start value of $J_W$: `paper_numbers.m` |
| Tables 6–8, Figs. 2–3 (tracking, per joint, gains) | `results/table_gains/summary.md` Sects. 1, 5, 8 and `results/table_gains/simulation_results.mat` |
| Table 9 (effort) | `results/table_gains/summary.md` Sect. 3; last column: `paper_numbers.m` |
| Table 10, Fig. 1(b) (ablation) | `results/ablation_runs/fopso_c2_*`, `fopso_gwo_c2_*`, `fopso_gwo_v1_*` and the final runs above |
| Torque of perfect tracking (7395 N m) | `paper_numbers.m` (inverse dynamics along the sinusoidal reference) |

To redraw the figures from the stored results (Python 3 with numpy, scipy and matplotlib):

```bash
python3 paper/figures/make_figures.py      # from the repository root
```

To print the remaining numbers, run `paper_numbers` in MATLAB (about a minute, or seconds
with the compiled simulation).
